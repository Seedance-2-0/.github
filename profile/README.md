# Seedance 2.0

**AI Video Generator — Multi-Shot, Cinematic, Consistent.**

Seedance 2.0 is a unified AI video creation platform built for creators, filmmakers, and teams who need cinematic-quality video generation with precise creative control.

---

## What We Do

Turn text, images, and references into stunning 2K videos — up to 15 seconds, up to 6 shots, all in one workspace.

**No more scattered tabs. No more platform-hopping. One place for everything.**

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Shot Director** | Script up to 6 shots per video with individual prompts and durations |
| **Reference-Driven Consistency** | Lock character, style, and color across outputs with up to 3 reference images |
| **First Frame → Last Frame** | Define keyframes for precise motion control and transitions |
| **Multimodal Inputs** | Combine text, images (up to 9), video (up to 3), and audio (up to 3) |
| **2K Output** | High-resolution video generation, 4–15 seconds |

## Use Cases

- **Social Media Creators** — Style-consistent short videos for TikTok, Reels, Shorts
- **Short Film & Narrative** — Multi-shot sequence scripting with frame-level control
- **Marketing & Ads** — Brand-consistent ad variants at scale
- **E-commerce** — Product transformation and reveal videos
- **Game Dev** — Concept art animation, cinematic trailers
- **Studios & Agencies** — Batch 2K video production via API
